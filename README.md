## How it works

1. Each `kata/N-name/` has `hints.md` (firmas, pistas, alternativas) and `*_test.go`
2. You implement the `.go` files
3. `go test ./kata/N-name/ -v` turns green
4. `git commit`

No walkthroughs. No spoon-feeding. Just katas.
